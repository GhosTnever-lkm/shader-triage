A

Three engine adapters

Strict patterns recognize common Unity, Unreal Engine, and Godot compiler messages. Lines that do not match stay unknown.

B

Repeat grouping

Equivalent diagnostics are grouped by normalized fields. The report keeps first and last line numbers and the original first line.

C

Evidence, not guesses

CPU time is labelled as CPU time. Variant-space totals are kept separate from compiled counts. No predicted causes or build-time totals.

SCOPE

What ShaderTriage can and can’t tell you

  • Reads one text file or pasted text up to 20 MiB.
  • Never edits source files or sends log content anywhere.
  • Parser coverage is version-dependent and incomplete.
  • It does not compile shaders, inspect project assets, or establish root cause.
